Редакційний кабінет

Матеріали, що проходять автоматичний фільтр, одразу публікуються. Тут можна перевірити першоджерело, підтвердити редакторську перевірку, залишити публікацію на перевірці або відхилити її. Зняті з публікації матеріали залишаються в бібліотеці.

Підключення бібліотеки GitHub

Для публічного репозиторію читання доступне без токена. Для запису потрібен fine-grained token із доступом лише до цього репозиторію та правом Contents: Read and write. Токен не зберігається в браузері й використовується лише для прямого звернення до GitHub API.

Безпека токена. Створіть fine-grained token, оберіть лише репозиторій liudiane-maibutnie, дозвольте тільки Contents: Read and write та встановіть короткий строк дії. Не використовуйте classic token із повним доступом. Код редактора не підключає сторонніх бібліотек і надсилає токен лише на api.github.com. Після збереження поле токена очищується.
Завантажте бібліотеку з GitHub або відкрийте локальний файл content/articles.json.
Зміни ще не збережені
Редакційна система «Людяне майбутнє». Автоматична класифікація допомагає сортувати матеріали, але остаточні редакційні рішення для спірних випадків ухвалює людина. Схвалення означає редакційну релевантність, а не незалежне підтвердження наукової істинності.
