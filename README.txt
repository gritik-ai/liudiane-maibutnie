ЛЮДЯНЕ МАЙБУТНЄ — БЕЗКОШТОВНИЙ СТАРТ
====================================

Ця версія не використовує OpenAI API, платну генерацію тексту, базу даних,
серверні секрети чи Vercel Cron. Автоматичне оновлення виконує GitHub Actions,
а матеріали надходять із заздалегідь визначених відкритих RSS-стрічок.

ВАЖЛИВА РІЗНИЦЯ
---------------
Це автоматична тематична добірка, а не AI-згенеровані аналітичні статті.
Система забирає заголовок, дату, посилання та короткий опис із RSS, відбирає
матеріали за тематичними словами, додає їх до content/articles.json і посилається
на першоджерело. Вона не перевіряє наукову методологію та не гарантує, що кожна
новина є виключно позитивною. Для цього потрібна людська перевірка або окремий
етап редакторського аналізу.

ЩО ВИКОРИСТОВУЄТЬСЯ
-------------------
- GitHub — зберігання коду та бібліотеки матеріалів.
- GitHub Actions — щоденний запуск RSS-скрипту.
- Vercel Hobby — безкоштовне розміщення персонального некомерційного сайту.
- Публічні RSS-стрічки MIT News, arXiv та UNESCO-UNEVOC.
- Python standard library — без платних пакетів і API-ключів.

ЖОДНІ ПАРОЛІ, API-КЛЮЧІ АБО ТОКЕНИ НЕ ПОТРІБНІ.

КРОК 1. СТВОРИТИ GITHUB-РЕПОЗИТОРІЙ
----------------------------------
1. Відкрий https://github.com/ і створи безкоштовний обліковий запис.
2. Натисни New repository.
3. Назва: liudiane-maibutnie.
4. Для найпростішого безкоштовного запуску обери Public. У репозиторії немає
   секретів; усі файли проєкту будуть відкритими. Якщо хочеш залишити код
   приватним, GitHub Free має обмежений місячний обсяг Actions для private repo.
5. Не додавай README, .gitignore або License — вони вже є у цьому пакеті.
6. Створи репозиторій.

КРОК 2. ЗАВАНТАЖИТИ ФАЙЛИ
-------------------------
1. Розпакуй ZIP-архів на комп'ютері.
2. Відкрий папку ai-for-humanity.
3. Завантаж УСІ файли та папки з її кореня до кореня GitHub-репозиторію.
   Важливо зберегти структуру папок, особливо:
   - .github/workflows/update-feed.yml
   - scripts/update_feed.py
   - content/articles.json
   - index.html
   - vercel.json
4. Після завантаження перевір, що на GitHub видно папки .github, scripts і content.

Якщо вебзавантажувач не дозволяє передати приховану папку .github, скористайся
безкоштовним GitHub Desktop: https://desktop.github.com/ . Клонуй репозиторій,
скопіюй у нього розпаковані файли та натисни Commit to main → Push origin.

КРОК 3. УВІМКНУТИ GITHUB ACTIONS
--------------------------------
1. У репозиторії відкрий вкладку Actions.
2. Знайди workflow Daily RSS update.
3. Якщо GitHub попросить, натисни Enable workflow.
4. Відкрий Daily RSS update → Run workflow → Run workflow.
5. Дочекайся завершення. Зелена позначка означає, що запуск завершився без помилки.
6. Якщо знайдено відповідні нові матеріали, workflow створить коміт із оновленим
   content/articles.json. Якщо нових матеріалів немає, коміт не створюється.

Щоденний запуск заплановано на 06:23 UTC. GitHub може затримувати заплановані
запуски при високому навантаженні; точний час не гарантується.

КРОК 4. РОЗГОРНУТИ САЙТ НА VERCEL
---------------------------------
1. Відкрий https://vercel.com/ і зареєструйся через GitHub.
2. Натисни Add New → Project.
3. Імпортуй liudiane-maibutnie.
4. Framework Preset: Other; Root Directory: ./; Build Command: залиш порожнім.
5. Натисни Deploy.
6. Vercel видасть безкоштовну адресу виду liudiane-maibutnie.vercel.app.
7. Кожен новий коміт у GitHub автоматично запускає нове розгортання Vercel.

ПЛАТА ТА ОБМЕЖЕННЯ
------------------
- OpenAI API не використовується; поповнювати баланс OpenAI не потрібно.
- У скрипті немає платних сторонніх API.
- GitHub Actions на стандартних GitHub-hosted runners безкоштовний для public
  repositories. Якщо обираєш private repository, слід стежити за місячним
  включеним лімітом свого плану.
- Vercel Hobby безкоштовний для персонального некомерційного використання.
  Якщо проєкт стане комерційним, перевір умови тарифу або обери інший хостинг.
- Безкоштовні тарифи й умови провайдерів можуть змінюватися.

ЯК ПЕРЕВІРИТИ, ЩО ВСЕ ПРАЦЮЄ
----------------------------
1. GitHub → Actions → Daily RSS update → Run workflow.
2. Перевір журнал запуску на кроці «Оновити добірку з RSS».
3. Якщо є нові матеріали, перевір коміт у content/articles.json.
4. Після коміту Vercel автоматично створить новий deployment.
5. Відкрий адресу Vercel та прокрути до бібліотеки матеріалів.

МОЖЛИВІ РЕЗУЛЬТАТИ
------------------
- «Додано N матеріал(ів)» — нові картки записані.
- «Нових матеріалів ... немає» — це нормальний результат, якщо немає нових
  матеріалів, які відповідають часовим і тематичним правилам.
- «Не вдалося отримати жодну RSS-стрічку» — повтори запуск пізніше та перевір
  доступність джерел.

SEO ТА ПОШУКОВА ІНДЕКСАЦІЯ
--------------------------
Публічний домен: https://liudiane-maibutnie-site.vercel.app/

- robots.txt: https://liudiane-maibutnie-site.vercel.app/robots.txt
- sitemap.xml: https://liudiane-maibutnie-site.vercel.app/sitemap.xml
- Публічні статті генеруються як окремі статичні сторінки у папці articles/.
- scripts/build_site.py створює сторінки статей, canonical URL, Open Graph,
  структуровані дані Article, sitemap.xml та robots.txt.
- Публічні статті, що пройшли автоматичний фільтр, потрапляють у sitemap.
  Матеріали зі статусом needs_review або rejected до нього не включаються.
- GitHub Actions оновлює статичні сторінки та sitemap після кожного RSS-запуску.
- Редакторський кабінет має meta robots noindex,nofollow і не додається до sitemap.

Локальні команди:
  python scripts/build_site.py --write
  python scripts/build_site.py --check

Після розгортання додай адресу сайту до Google Search Console як URL-prefix
property та надішли sitemap.xml у розділі Sitemaps. Так само можна додати сайт
до Bing Webmaster Tools і подати той самий sitemap. Сам факт подання sitemap
не гарантує індексацію: пошукові системи самостійно вирішують, які сторінки
сканувати, індексувати та показувати в результатах.

РЕДАКЦІЙНІ ПРИНЦИПИ
------------------
1. Публікувати лише матеріали з визначених джерел і з перевірюваними URL.
2. Не копіювати повні статті; показувати заголовок і короткий фрагмент RSS,
   обов'язково давати посилання на оригінал.
3. Для arXiv позначати матеріал як препринт, який не обов'язково пройшов
   незалежне рецензування.
4. Не подавати тематичний RSS-відбір як фактчекінг або експертну оцінку.
5. Не робити висновків, які не підтверджуються самим матеріалом.
6. Позитивний напрям проєкту не означає приховування ризиків чи критичних новин.
7. ШІ — радник і інструмент; права, свободи й рішення людей залишаються
   центральними принципами.

Як змінювати RSS-джерела та ключові слова: відредагуй scripts/update_feed.py.
Не додавай джерело, доки не перевіриш його власника, URL і правила використання.
